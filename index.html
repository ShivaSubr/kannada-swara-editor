Keyboard typing: Click in the composition and type S R G M P D N (lowercase also works) to insert Kannada swaras. Select lower/middle/upper octave on the left. Use Ctrl+1 for single underline, Ctrl+2 for double underline, Ctrl+0 to remove. Spaces and Enter work normally.

Type S R G M P D N directly in the composition, or use the buttons. Octave dots are drawn above or below the whole Kannada swara, not with Unicode combining marks. You may type text directly, but use the swara buttons for correctly positioned octave dots. For a duration, place the cursor after the swara or select the swara, then click a duration button.

Search by raga name or Melakarta number, choose a result, and press Fill scales. This replaces the two scale lines, not your composition. You can still edit both lines manually. Subscript digits ₁ ₂ ₃ indicate swara variants.

Save Project creates an editable JSON file. Use Open Project to continue later. The standalone HTML option saves a copy of this editor with your current notes embedded. PDFs are for printing, not re-editing. Plain text copy uses Unicode dots, which may not align perfectly in other applications.

Help · ಸ್ವರ ಸಂಕೇತಗಳ ಮಾರ್ಗದರ್ಶಿ

Octaves: Select ಕೆಳ ಸ್ಥಾಯಿ for a dot below (lower octave), ಮಧ್ಯ ಸ್ಥಾಯಿ for no dot, or ಮೇಲಿನ ಸ್ಥಾಯಿ for a dot above (upper octave), then click a swara.

Keyboard: In the composition editor, S R G M P D N (uppercase or lowercase) insert Kannada swaras. Other keys retain normal typing. Ctrl+1 / Ctrl+2 / Ctrl+0 apply single / double / no underline to a selected swara or the swara just before the cursor.

Underlines: Select a swara, or put the cursor immediately after it, then use Single underline, Double underline, or Remove underline. Underlines are retained in saved projects and printouts.

Deergha: ಸ, adds one duration unit; ಸ; adds two; ಸ,, also adds two. Place the cursor immediately after a button-inserted swara before clicking the duration mark.

Tala: Use | for a division and || for a double division. Space and New line buttons separate phrases.

Automatic saving: Your edits are saved in this browser on this device. It is not cloud sync. Use Save Project to download a backup, and Open Project to resume on another computer. Browser storage can be cleared, so keep JSON backups.

Raga scale: Select a raga from the library and click Fill scales, or type the Aarohana and Avarohana in their separate editable lines above the composition. Use Unicode subscripts ₁ ₂ ₃ for swara variants. Both are saved and printed.

Printing: Use Print / Save PDF and select “Save as PDF” in the print dialog. The title, raga, tala and composer appear above the swaras. Octave dots are drawn independently of Kannada font combining-mark support.
